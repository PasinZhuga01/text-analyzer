## Deployment

Application deployed on Vercel:

https://my-text-analyzer-two.vercel.app/

## Features

- Text editing
- Symbol counter
- Word counter
- Synonyms search
- Replace selected text with synonym
- Сopy to сlipboard in one click
- Toast notifications

## Technologies

- Angular
- TypeScript
- ESLint
- Prettier

## Installation and local launch

Clone repository:

```bash
git clone <repository-url>
```

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run start
```

Application will be available at:

```text
http://localhost:4200
```

## Scripts

### Start development server

```bash
npm run start
```

Runs application in development mode.

---

### Build application

```bash
npm run build
```

Creates production build.

---

### Run linter

```bash
npm run lint
```

Checks project code with ESLint.

---

### Format code

```bash
npm run format
```

Formats project files with Prettier and fixes ESLint issues.
